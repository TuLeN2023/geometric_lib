# Общее описание решений
Данная библиотека представляет собой совокупность функций, написанных на питоне для разных вычислений, связанных с геометрией
Данный проект может:
* Вычислять площади таких фигур, как треугольник, прямоугольник, квадрат, круг
* Вычислять периметры таких фигур, как треугольник, прямоугольник, квадрат, окружность
* Вычислять разные радиусы у треугольников и прямоугольников
# Структура файлов
Всего представлено 4 файла с функциями, а также сама документация, далее распишем каждый файл
## Файл rectangle
### Функция area(a,b)
**Сигнатура функции следующая:**
```
area(a,b)
a - одна сторона прямоугольника, float
b - другая сторона прямоугольника, float
```
Мы возвращаем значение площади для нашего прямоугольника по формуле $S = a b $.
Вот код, который считает и возвращает значение площади:
```
return a * b
return - возвращает значение функции
a * b - получаем значение площади по формуле
```
**Примеры использования**
```python
>>> area(3,5)
15
>>> area(4,1)
4
>>> area(1.19, 13.23)
15.7437
```
### Функция perimeter(a,b)
**Сигнатура функции следующая:**
```
perimeter(a, b)
a - одна сторона прямоугольника, float
b - другая сторона прямоугольника, float
```
Мы возвращаем значение периметра для нашего прямоугольника по формуле $P = 2 (a + b)$.
Вот код, который считает и возвращает значение периметра:
```
return (a + b)*2
return - возвращает значение функции
(a + b)*2 - получаем значение периметра
```
**Пример использования**
```python
>>> perimeter(2,5)
14
>>> perimeter(1.9, 5.3)
14.399999999999999
```

### Функция radius(a,b)
**Сигнатура функции следующая:**
```
radius(a, b)
a - одна сторона прямоугольника, float
b - другая сторона прямоугольника, float
```
Мы возвращаем значение радиуса описанной окружности для нашего прямоугольника по формуле $R = \frac{\sqrt{a^2 + b^2}}{2}$.
Вот код, который считает и возвращает значение радиуса:
```
return (a**2+b**2)**(1/2)/2
return - возвращает значение функции
(a**2+b**2)**(1/2)/2 - получаем значение радиуса
```
**Пример использования**
```python
>>> radius(2,5)
2.692582403567252
>>> radius(1.9, 5.3)
2.8151376520518494
```


## Файл circle
**`Замечание`**\
В начале кода мы импортируем стандартную библиотеку math:
`import math`

### Функции
#### Функция area(r)
**Сигнатура функции следующая:**
```
area(r)
r - радиус нашей окружности, float
```
Мы возвращаем значение площади для нашего круга по формуле $S = \pi r^2 $.
Вот код, который считает и возвращает значение площади:
```
return math.pi * r * r
return - возвращает значение функции
math.pi - импорт константы из библиотеки
math.pi * r * r - получаем значение площади по формуле
```
**Примеры использования**
```python
>>> area(1)
3.141592653589793
>>> area(4)
50.26548245743669
```
#### Функция perimeter(r)
**Сигнатура функции следующая:**
```
perimeter(r)
r - радиус нашей окружности, float
```
Мы возвращаем значение периметра (длины) для нашей окружности по формуле $C = 2 \pi r $.
Вот код, который считает и возвращает значение периметра:
```
return 2 * math.pi * r
return - возвращает значение функции
math.pi - импорт константы из библиотеки
2 * math.pi * r - получаем значение периметра
```
**Пример использования**
```python
>>> perimeter(13)
81.68140899333463
>>> perimeter(2.5)
15.707963267948966
```

## Файл triangle
### Функции
#### Функция area(a,h)
**Сигнатура функции следующая:**
```
area(a,h)
a - сторона треугольника, float
h - высота, проведенная к этой стороне, float
```
Мы возвращаем значение площади для нашего треугольника по формуле $S = \frac{ah}{2} $.
Вот код, который считает и возвращает значение площади:
```
return a*h/2
return - возвращает значение функции
a*h/2 - получаем значение площади по формуле
```
**Примеры использования**
```python
>>> area(1,2)
1
>>> area(4,3)
6
>>> area(1.73, 1.65)
1.42725
```
#### Функция perimeter(a,b,c)
**Сигнатура функции следующая:**
```
perimeter(a,b,c)
a - первая сторона треугольника, float
b - вторая сторона треугольника, float
c - третья сторона треугольника, float
```
Мы возвращаем значение периметра для нашего треугольника по формуле $P = a+b+c $.
Вот код, который считает и возвращает значение периметра:
```
return a+b+c
return - возвращает значение функции
a+b+c- получаем значение периметра
```
**Пример использования**
```python
>>> perimeter(2,2,3)
7
>>> perimeter(3, 5, 7)
15
```
#### Функция radius_inscribed_circle(s, p)
**Сигнатура функции следующая:**
```
radius_inscribed_circle(s, p)
s - площадь треугольника, float
p - полупериметр треугольника, float
```
Мы возвращаем значение радиуса вписанной в наш треугольник окружности по формуле $r = \frac{S}{p} $.
Вот код, который считает и возвращает значение радиуса:
```
return s/p
return - возвращает значение функции
s/p- получаем значение радиуса по формуле
```
**Примеры использования**
```python
>>> radius_inscribed_circle(5, 4)
1.25
>>> radius_inscribed_circle(50, 10)
5.0
>>> radius_inscribed_circle(178, 110)
1.6181818181818182
```
